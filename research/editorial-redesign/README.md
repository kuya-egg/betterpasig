# BetterPasig editorial redesign

The homepage pairs a licensed photograph of Pasig City Museum with a service search and a tray of links to common tasks. The city showcase uses an asymmetric photo layout, and service answers use a separate facts panel next to the requirements and steps. The shared design uses Newsreader, Plus Jakarta Sans, warm paper surfaces, and Pasig Blue for interactive elements. [High-End Visual Design skill](https://www.skills.sh/leonxlnx/taste-skill/high-end-visual-design) · [Taste Skill repository](https://github.com/leonxlnx/taste-skill) · [Photo and license records](../../data/photos.json)

The Filipino copy branch is included in the PR history. Barangay maps, detail pages, and the barangay officials directory use Filipino on both language routes. Existing English-route links still resolve.
